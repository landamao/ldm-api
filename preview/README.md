# 新版界面预览（不参与构建）

这是重排管理端信息架构的**静态预览**，和 `web/` 里的正式前端完全分开：
`build.sh` 不会打包它，`web/embed.go` 也不会嵌入它。

## 怎么打开

在仓库根目录起一个静态服务（需要一个能读到 `../web/assets` 的根目录）：

```bash
cd D:/code/ldm-api
python -m http.server 8777 --bind 127.0.0.1
```

然后访问：<http://127.0.0.1:8777/preview/>

也可以直接双击 `preview/index.html`，但部分浏览器在 `file://` 下会拦截同源资源，推荐用上面的方式。

## 这版的信息架构

```
顶栏（左上角玻璃岛，右上是齿轮）
├─ 首页        → 在线聊天（会话列表 / 消息 / 参数面板）
├─ 用量数据    → 左侧三个视图：数据看板 / 渠道用量 / 调用日志
├─ 模型广场    → 大字标题 + 左侧筛选 + 卡片网格（无价格体系）
├─ 模型管理    → 四列工作台，左边渠道×渠道模型，右边模型×路由
└─ 齿轮        → 整页设置：令牌管理 / 站点信息 / 安全 / 数据与运行
```

### 模型管理（这版的重点）

- 左半边两列：**渠道列表** → 选中渠道的**渠道模型**。渠道行直接显示 ID、名称、类型、地址、模型数、启用/编辑/删除；渠道模型列带提供商筛选、获取模型列表、右上角加号（手填上游模型名）。
- 右半边两列：**已添加模型** → **路由**。自定义模型排在前面；渠道模型点开是详情和「被哪些路由引用」。
- 把左侧渠道模型**拖到右侧**：
  - 拖到某个自定义模型行上会先展开它的路由，松手追加一条；
  - 拖到路由列表里会按绿色插入线落到对应位置，拖进分组会自动继承组号；
  - 拖的是还没接入模型管理的渠道模型时，会自动把它加进模型管理。
- 路由之间可以拖把手排序、整组拖动、上移/下移、合并成组、移出分组、改组内权重。
- **未保存的路由按模型缓存**：切渠道、切模型、拖拽经过别的模型都不会丢草稿；模型行上有小黄点提示。

## 预览里哪些是真的、哪些是假的

所有页面都按真实接口的字段和结构写（`/api/channels`、`/api/models`、`/api/models/available`、`/api/plaza`、`/api/logs`、`/api/stats/*`、`/api/tokens`、`/api/settings`）。当前的交互跑在 `js/data.js` 的演示数据上：

- 聊天回复、渠道测试、模型测试是本地模拟的；
- 保存渠道 / 模型 / 路由 / 令牌只改内存，刷新页面会还原；
- 备份导出只展示路径和计数，不写文件；
- 登录、改密码、退出登录不真的请求后端。

把预览定稿后搬进正式前端的做法：把 `data.js` 里的读取函数换成 `API.get('/api/...')`，写操作换成对应的 POST/PUT/DELETE，页面结构和交互可以整块复用。字段对照在每段 mock 的注释里。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 入口，复用 `web/assets` 下的样式、marked、KaTeX、provider 图标、charts |
| `css/preview.css` | 新骨架布局；颜色/按钮/卡片/徽章/表格/弹窗全部沿用 `web/assets/app.css` |
| `js/util.js` | 图标、Toast、气泡、弹窗、抽屉、格式化、主题（与线上同一套行为） |
| `js/data.js` | 演示数据 + 统计/日志派生，字段对齐真实接口 |
| `js/chat.js` | 首页在线聊天 |
| `js/usage.js` | 数据看板 / 渠道用量 / 调用日志 |
| `js/plaza.js` | 模型广场 |
| `js/models.js` | 模型管理四列工作台 + 拖拽路由 + 渠道编辑页 |
| `js/settings.js` | 设置整页（令牌 / 站点 / 安全 / 数据） |
| `js/app.js` | 顶栏与路由 |

## 已知取舍

- 路由拖拽用原生 HTML5 drag & drop；触摸屏上暂不支持（正式版可以换指针事件或加「选择模型」按钮的入口，预览里已经有这个按钮）。
- 演示数据固定到「今天 20:12」，保证首次打开就能看到一整天的曲线，不是真实时钟。
- 手机宽度下四列工作台会折叠成单列，仍可操作。
